How it works

Layered local analysis

URLs are scored on structure: IP hosts, @ tricks, punycode, deep subdomains, risky TLDs, shorteners, and brand names on domains that don’t belong to the brand. Typosquats are found by edit distance after undoing look-alike characters.

Email analysis

Sender and reply-to domains, SPF/DKIM/DMARC results from pasted headers, urgency and credential-request language, embedded links, and risky attachment names. Flagged sentences are highlighted.

Score, not probability

The 0–100 score is a hand-weighted heuristic. It is not a calibrated probability: a score of 70 does not mean a 70% chance of phishing. Calibration needs a labelled dataset and a trained model.

Production architecture

React + TypeScript frontend; Express API with validation, rate limiting and SSRF guards; a Python ML service; a database for history; server-side adapters for Safe Browsing, VirusTotal, PhishTank and URLhaus.
